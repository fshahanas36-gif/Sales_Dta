# 📊 Sales Data Dashboard – Excel

## 📌 Project Overview

This project is an **interactive Sales Data Dashboard created using Microsoft Excel**.
It analyzes sales performance across different **regions, products, months, and salesmen** and presents the insights through an easy-to-understand dashboard.

The project demonstrates the use of **Excel data analysis, Pivot Tables, Pivot Charts, formulas, and dashboard design**.

## 📂 Dataset

The dataset contains **366 sales records** with information including:

* 📅 Date
* 👤 Salesman
* 🌍 Region
* 🛒 Product / Item
* 📦 Quantity
* 💰 Price
* 💵 Sales Amount

## 📊 Dashboard Analysis

The dashboard provides insights into:

* **Monthly Sales Performance**
* **Sales by Region**
* **Sales by Product**
* **Quantity Sold by Product**
* **Salesman Performance**
* **Overall Sales & Quantity KPIs**

### 🏆 Key Insights

* **East** generated the highest regional sales.
* **Printer** was the highest-selling product by sales amount.
* **Printer** also had the highest quantity sold.
* The dashboard allows sales performance to be analyzed across multiple dimensions.
